# Yasmyna Feraru

Medicine and Computer Engineering student in Italy.

I work on BTH, a post-stroke upper-limb rehabilitation exosuit, and on clinical AI safety: measuring how
language models fail on clinical tasks.

BTH is a research prototype, not a medical device.

## Featured

- [BTH](https://github.com/yasferaru/bth-showcase): a per-patient adaptive exosuit for post-stroke elbow and shoulder rehabilitation, with autonomic sensing. Hardware runs end to end on the bench; software tested on a seeded simulator only; no patient data.
- [Clinical LLM Safety Lab](https://github.com/yasferaru/clinical-llm-safety-lab): measures how language models fail on clinical safety tasks (emergency triage, dosing, sycophancy under pressure), plus a prompt-injection test on patient notes. v0, in progress: the harness is built, the full evaluation has not been run yet.
- [BTH governance layer](https://github.com/yasferaru/bth-governance-showcase): how to put a language model inside a closed-loop clinical wearable without giving it authority. Simulated data and a mock model only.
